# Contribution Guidelines

I'll accept pretty much any PR (except Spam, Malware, and *genuinely* bad stuff), but here are some things you should know:

- **New Language Additions** will likely have to wait a bit longer (it's hard for me to review languages I don't know), but still cool!
- **Please try compiling the package** before opening a PR (if you couldn't do so for whatever reason, please tell me in the PR).
- **The usual rules:** No Spam, No Insults, No Bad Language, No Discrimination. You get the point.
